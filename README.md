## 使用方式

先阅读资源说明，再从源仓库安装所需 Skill。每个 Skill 的代码与工作流程在其源仓库维护，本目录记录入口和已核对的版本。

GitHub 收录与本机安装是两个独立步骤。需要在 Codex 中调用某个 Skill 时，请将其完整 Skill 目录安装到目标环境；ChatGPT 插件需要另行打包和安装。

## 维护方式

新增 Skill 时，在上表增加一行，并在 `resources/` 中补充介绍、实际 Skill 路径、依赖与源版本。源仓库更新后，重新核对并更新对应说明。
